go2 강화학습

2026.08

Isaac Lab 기반 Unitree Go2 강화학습 환경에 IMU 센서를 부착하고, 정책 재생 중 IMU 값 출력과 실시간 그래프 확인 기능을 추가한 프로젝트입니다.

이 프로젝트는 Unitree Go2 로봇의 locomotion 강화학습 환경을 Isaac Lab에서 구성한 코드입니다. 기존 Go2 환경에 IMU 센서를 추가하고, 정책이 학습·재생되는 동안 로봇의 흔들림과 기울어짐을 더 직접적으로 확인할 수 있도록 관측값, 보상항, 그래프 출력 흐름을 정리했습니다.

  • 작업 시기 2026년 8월
  • 내 작업 파트 Go2 IMU 센서 부착, IMU 기반 관측·보상 설정, 정책 재생 중 IMU 출력과 live plot 기능 구성
  • 주요 기술 Python, Isaac Lab, RSL-RL, Unitree Go2, IMU, Matplotlib

구현 방식

  • UnitreeGo2RoughEnvCfg에 ImuCfg를 추가해 Go2 base 링크 기준 IMU 센서를 부착했습니다.
  • 정책 관측 순서를 gyro, projected gravity, linear acceleration, command, joint state, previous action 순서로 정리해 실제 Go2 policy runner와 맞추도록 구성했습니다.
  • imu_ang_vel_xy_l2, imu_orientation_l2, imu_lin_acc_l2 보상항으로 roll/pitch 흔들림과 과도한 가속을 penalty로 반영했습니다.
  • flat/rough 환경을 나누고, play 전용 설정에서는 환경 수와 randomization을 줄여 정책 확인이 쉽도록 구성했습니다.
  • scripts/rsl_rl/play.py에 --print_imu, --plot_imu 옵션을 추가해 IMU 값을 콘솔과 실시간 그래프로 확인할 수 있게 했습니다.

그래프 설정

정책 재생 시 ImuLivePlotter가 2x2 그래프를 띄워 gyroscope, accelerometer, projected gravity, 흔들림 지표를 함께 보여줍니다. 이를 통해 정책이 앞으로 이동하는지만 보는 것이 아니라, 몸체가 얼마나 흔들리는지와 기울어짐이 누적되는지를 확인할 수 있습니다.

공개 저장소 정리

공개 저장소에는 소스 코드와 설정 파일만 남겼고, 학습 로그, TensorBoard 이벤트, 모델 체크포인트, ONNX/PT 정책 파일, logs/, outputs/, 캐시 파일은 제외했습니다.
