LLM 학교 축제 쿠지 게임

2026.04.16–2026.04.21

llm을 활용한 2026년 학교 축제용 쿠지 게임 제작 프로젝트입니다. Unity UI와 C# 스크립트로 카드 선택, 랜덤 선택, 보상 셔플, 드래그 공개 연출, 결과 영상 재생 흐름을 구현했습니다.

프로젝트 설명

이 프로젝트는 학교 축제 현장에서 쿠지 뽑기 이벤트를 진행하기 위해 만든 Unity 기반 게임입니다. 사용자가 뽑을 카드 수를 정하고, 직접 선택 또는 랜덤 선택으로 카드를 고른 뒤, 드래그 연출을 통해 결과를 공개하는 구조로 제작했습니다. 기획과 화면 구성 과정에서는 llm을 활용한 2026년 학교 축제용 쿠지 게임 제작이라는 방향을 중심에 두고, 현장에서 바로 이해할 수 있는 UI 흐름을 우선했습니다.

  • 제작 기간 2026년 4월 16일 ~ 2026년 4월 21일
  • 프로젝트 목적 학교 축제 부스에서 사용할 수 있는 쿠지 카드 선택·결과 공개 게임 제작
  • 주요 기술 Unity, C#, TextMeshPro, Unity UI, VideoPlayer, Coroutine

시연 영상

구현 방식

  • GameManager를 싱글톤 형태로 두고 선택 목표 수, 현재 선택 카드 목록, 시작 패널과 카드 패널 전환, 버튼 활성화 조건을 한 곳에서 관리했습니다.
  • SelectableCard는 Button과 Outline 컴포넌트를 요구하도록 구성해, 선택 가능 여부와 선택 시 glow/scale 피드백을 카드 단위로 처리했습니다.
  • StartButton에서 A상~F상 보상 풀을 만들고 셔플한 뒤 카드에 배정해, 실행할 때마다 결과 배치가 고정되지 않도록 했습니다.
  • RandomSelectButton은 선택 가능한 카드만 후보로 모아 무작위 선택하고, 실제 선택 등록은 GameManager.TrySelect()로 통일해 직접 선택과 랜덤 선택 흐름이 어긋나지 않게 했습니다.
  • ResultManager는 선택된 카드를 순서대로 공개하며, 마우스 드래그 거리와 threshold를 이용해 앞면 이미지가 줄어들고 결과가 나타나는 reveal 연출을 구현했습니다.
  • VideoController는 결과 공개 후 Unity VideoPlayer를 재생하고, 영상 종료 이벤트에서 다음 카드로 넘어가는 흐름을 연결했습니다.

정리 포인트

단순한 버튼 클릭 뽑기가 아니라 선택 개수 제한, 진행도 표시, 랜덤 선택, 카드 공개 연출, 보상 잔여량 표시, 영상 재생 후 다음 카드 진행까지 하나의 사용 흐름으로 연결했습니다. Unity 프로젝트 특성상 공개 저장소에는 제공받은 Assets/ 구조를 유지하고, Library/, Temp/, 빌드 결과물, 캐시 파일은 제외했습니다.
