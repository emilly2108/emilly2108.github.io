ROS 2 기반 자율주행 및 SLAM 기술

ROS 2 기반 자율주행 및 SLAM 기술은 로봇 소프트웨어 분야에서 널리 사용되는 핵심 기술 중 하나임. SLAM은 Simultaneous Localization and Mapping의 약자로, 로봇이 주변 지도를 만들면서 동시에 자신의 위치를 추정하는 기술을 의미함. 사람이 처음 가보는 건물에서 주변을 관찰하며 지도를 기억하고 자신의 위치를 파악하는 것처럼, 로봇도 센서를 이용해 주변 환경을 인식하고 지도를 생성하며 이동할 수 있음.

SLAM의 활용 분야
자율주행 로봇, 배달 로봇, 청소 로봇, 공장 물류 로봇, 드론 등 다양한 분야에서 활용됨. 특히 ROS 2와 함께 사용되면서 로봇 개발의 표준 기술처럼 자리 잡고 있음.

ROS 2는 Robot Operating System 2의 약자. 로봇의 센서 데이터 처리, 경로 계획, 로봇 제어, 노드 간 통신 등을 쉽게 구현할 수 있도록 도와주는 오픈소스 소프트웨어 플랫폼임. 다양한 패키지와 도구를 제공하여 복잡한 로봇 시스템을 모듈 단위로 개발할 수 있음.

SLAM의 핵심 개념

SLAM은 로봇이 이동하면서 주변 환경의 지도를 생성하고 동시에 지도 안에서 자신의 위치를 추정하는 기술임.

지도 생성 + 위치 추정 -> SLAM

SLAM의 기본 동작 과정

센서로 주변 환경 정보 수집 -> 벽, 장애물, 통로 등의 구조 파악 -> 주변 환경을 지도에 반영 -> 현재 센서 데이터와 이전 관측 정보 비교 -> 지도 속 로봇의 위치 추정 -> 새로운 위치와 환경 정보를 다시 지도에 반영

SLAM에 사용되는 센서

LiDAR는 레이저를 이용해 주변 물체까지의 거리를 측정하며, 거리 정보를 바탕으로 주변 환경의 구조를 파악하는 데 사용됨. 카메라는 이미지 정보를 이용해 주변 환경과 특징점을 인식함. 깊이 센서는 각 픽셀의 거리 정보를 측정하여 공간을 입체적으로 이해하는 데 사용됨. IMU는 가속도와 회전 정보를 측정하여 로봇의 움직임과 자세를 추정하는 데 사용됨.

2차원 SLAM

2차원 SLAM은 평면 형태의 지도를 생성하는 방식. 주로 실내 바닥을 기준으로 벽, 장애물, 통로 등을 표현함. 계산량이 비교적 적고 이동 로봇의 실내 자율주행에 적합함.

3차원 SLAM

3차원 SLAM은 3D LiDAR나 카메라를 이용하여 주변 환경을 입체적으로 인식하는 방식. 건물 내부의 높이, 계단, 경사로, 천장, 복잡한 구조 등을 파악할 수 있음. 2차원 SLAM보다 더 많은 정보를 얻을 수 있지만 계산량과 시스템 요구사항이 증가함.

Semantic SLAM

Semantic SLAM은 단순히 공간의 형태만 인식하는 것이 아니라 주변 객체의 의미까지 구분하는 기술임. 센서 데이터와 인공지능을 결합하여 사람, 의자, 문, 책상, 자동차 등의 객체를 인식하고 지도에 의미 정보를 추가함.

기본 SLAM -> 공간의 위치와 구조 파악

Semantic SLAM -> 공간의 위치와 구조 + 객체의 의미 파악

ROS 2 기반 자율주행 흐름

센서 데이터 수집 -> SLAM으로 지도 생성 -> 로봇의 현재 위치 추정 -> 목적지 설정 -> 경로 계획 -> 장애물 회피 -> 모터 제어 -> 목적지 도착

자율주행에서 SLAM의 역할

SLAM은 로봇이 주변 환경을 이해하고 자신의 위치를 파악할 수 있도록 함. 자율주행 시스템에서는 SLAM이 생성한 지도와 위치 정보를 바탕으로 경로 계획과 장애물 회피를 수행함.

SLAM -> 지도와 위치 정보 제공

경로 계획 -> 목적지까지 이동 경로 생성

제어기 -> 생성된 경로에 따라 로봇 움직임 제어

대표적인 ROS 2 관련 패키지

Cartographer

Google에서 개발한 SLAM 패키지. LiDAR와 IMU 등의 센서 데이터를 활용하여 실시간으로 지도를 생성할 수 있으며, 실시간 지도 작성 성능이 뛰어남.

RTAB-Map

카메라와 RGB-D 센서를 활용한 SLAM에 강점을 가진 패키지. 3차원 지도 생성과 장소 인식 기능을 제공하며 실내 환경을 입체적으로 표현하는 데 적합함.

ORB-SLAM3

카메라와 IMU를 활용하는 시각 SLAM 시스템. 카메라 영상에서 특징점을 추출하여 로봇의 위치와 주변 환경을 추정함. 단안 카메라, 스테레오 카메라, RGB-D 카메라 등을 활용할 수 있음.

Nav2

Navigation2의 약자. ROS 2에서 자율주행 기능을 구현하기 위한 핵심 프레임워크. 생성된 지도와 로봇의 위치 정보를 바탕으로 목적지까지의 경로를 계획하고 장애물을 피해 이동하도록 제어함.

SLAM과 Nav2의 관계

센서 데이터 -> SLAM -> 지도 생성 및 위치 추정 -> Nav2 -> 경로 계획 및 장애물 회피 -> 로봇 제어

SLAM은 로봇이 어디에 있고 주변 환경이 어떤지 파악하는 역할을 담당하고, Nav2는 해당 정보를 이용해 목적지까지 이동하는 역할을 담당함.

실제 활용 예시

병원 배달 로봇은 병원 내부의 지도를 생성하고 병실의 위치를 파악한 뒤 환자에게 약품이나 물품을 전달할 수 있음. 물류 창고의 AGV 로봇은 창고 지도를 바탕으로 물건의 위치까지 이동하고 지정된 장소로 물품을 운반할 수 있음. 청소 로봇은 집이나 건물 내부를 이동하면서 공간을 지도화하고 청소한 영역과 청소하지 않은 영역을 구분할 수 있음. 드론은 카메라와 IMU를 이용해 GPS가 없는 실내나 복잡한 공간에서 자신의 위치를 추정하며 이동할 수 있음.

SLAM의 장점

로봇이 GPS 없이도 실내에서 자신의 위치를 추정할 수 있음. 주변 환경을 기반으로 지도를 직접 생성할 수 있음. 생성된 지도와 위치 정보를 자율주행에 활용할 수 있음. 다양한 센서와 결합하여 복잡한 환경을 인식할 수 있음. ROS 2의 다양한 패키지와 연동하여 실제 로봇 프로젝트로 확장할 수 있음.

SLAM의 한계와 해결 과제

사람이 많은 환경에서는 센서가 사람의 움직임까지 인식하기 때문에 위치 추정이 어려워질 수 있음. 복잡한 3차원 환경에서는 많은 계산량과 높은 성능의 하드웨어가 필요함. 센서의 측정 오차가 누적되면 지도와 위치 추정 결과가 부정확해질 수 있음. 카메라 기반 SLAM은 조명 변화나 어두운 환경의 영향을 받을 수 있음. 비슷한 공간이 반복되는 환경에서는 로봇이 현재 위치를 잘못 판단할 수 있음.

SLAM의 주요 문제

센서 오차 -> 위치 추정 오차 -> 지도 왜곡
조명 변화 -> 특징점 인식 실패 -> 카메라 기반 위치 추정 성능 저하
동적 장애물 -> 환경 정보 변화 -> 지도와 실제 환경의 불일치
복잡한 3D 환경 -> 계산량 증가 -> 실시간 처리 어려움

ROS 2와 SLAM을 공부할 때 필요한 기술

ROS 2의 노드, 토픽, 서비스, 액션 구조를 이해해야 함. LiDAR, 카메라, IMU 등 센서 데이터를 처리하는 방법도 알아야 함. 좌표계와 TF 개념을 이해해야 하며, 로봇의 위치와 자세를 표현하는 방법을 익혀야 함. 컴퓨터 비전, 로봇 제어, 경로 계획, 센서 융합, Linux 환경에 대한 지식도 함께 필요함.

학습 및 프로젝트 구성

센서 데이터 확인 -> RViz에서 센서 정보 시각화 -> SLAM 패키지 실행 -> 지도 생성 -> 지도 저장 -> Nav2 설정 -> 목적지 지정 -> 자율주행 테스트

실제 프로젝트 확장

Jetson Orin Nano와 ROS 2를 사용하면 LiDAR, 카메라, 모터 제어기를 연결하여 실제 자율주행 로봇 프로젝트로 확장할 수 있음. 센서 데이터 수집 -> SLAM 지도 생성 -> Nav2 경로 계획 -> 모터 제어 순서로 시스템을 구성할 수 있음.
