원본 자료: 강화학습을 위한 신경망 기초 1주차: MLP·순전파·손실함수·경사하강법

기술 블로그 글을 작성할 때 참고한 원문입니다. 본문과 비교해 정리·편집된 범위를 확인할 수 있습니다.

강화학습 이론 1주차(mlp,순전파, 손실함수, 경사하강법).md

1\. MLP
MLP는 여러 개의 완전연결층으로 구성된 신경망입니다.

입력층 → 은닉층 → 은닉층 → 출력층



입력층 (Input Layer): 원시 데이터
은닉층 (Hidden Layer): 입력 데이터를 분석하고 특징을 추출하는 중간 단계

출력층 (Output Layer): 최종적으로 행동 명령


인공 뉴런(Neuron / Node) = '단일 판단 세포'
MLP의 최소 단위는 하나의 뉴런(노드)입니다.
수많은 '판단 세포'가 있습니다.하나의 뉴런은 다음과 같이 작동합니다.여러 개의 입력 신호(x)를 받는다.
각 신호의 중요도(가중치 w)를 곱해서 다 더한다 (sum x x w).

거기에 기본 성향(편향 b)을 더한다.
활성화 함수(f)를 거쳐 다음 세포로 신호를 보낼지 말지 결정한다.text{출력} = f(w\_1 x\_1 + w\_2 x\_2 + ... + b)

다 더하는 이유
한가지의 입력만으로 완벽한 상황을 알수 없으므로 여러가지 상황에 각 가중치를 주고 종합하여 상황을 판단
편향을 더하는 이유:입력값이 0이어도 존재하는 '기본 성향이나 민감도'를 반영하기 위해서
			 판단의 기준선(Threshold)을 통째로 올리거나 내리는 '기본 준비 상태' 역할
 활성화 함수(f)를 거치는 이유
'어중간한 연산 결과'를 '명확한 행동(0 아니면 1, 혹은 비율)'으로 바꾸기 위해서
만약 활성화 함수를 거치지 않는다면
가중합과 편향을 더해서 나온 종합 점수가 +35.8 또는 -102.4 같은 숫자라고 할시
.이 숫자를 그대로 다음 뇌세포로 전달하면 문제점이 생긴다.

신호의 폭주: 층을 거칠수록 숫자가 몇 천, 몇 억으로 계속 커져서 과부하
선택의 불분명함: 실행 할 것인가(1), 말 것인가(0)"를 결정해야지, "35.8만큼 실행해라"는 명령을 수행할 수 없다.

활성화 함수(ReLU) 적용:

종합 점수가 마이너스(< 0)면? 신호 차단 (0) -> "실행하지마!
"종합 점수가 양수(> 0)면? 신호 전달 (X)  "점수가 높을수록 세게 출력해라!"

\[ 양수 그대로 출력]



2\. 순전파
순전파는 입력값이 은닉층을 거쳐 출력값(예측값)까지 앞으로 쭉 전달되는 과정
입력: 정보가 들어옴

연산(가중치 곱과 활성화): 데이터(가중치 W)를 바탕으로 뇌가 빠르게 동작 경로 계산

출력: 예측 결과 발생


Step 1. 입력층

은닉층 연산 (기초 판단 수립)

입력값 \[x\_1, x\_2] = \[2, 3]이 은닉층의 두 뉴런(h\_1, h\_2)으로 전달된다.

이때 형성된 가중치(w)와 편향(b)이 적용

\[입력 데이터]       ---(가중치 w)--->       \[은닉 뉴런]

x1 = 2  	        --- (h1 연결선들) --->      h1

x2 = 3               --- (h2 연결선들) --->      h2



1\) 은닉 뉴런 h\_1

가중치 지정:  정보1(w\_11=1.5), 정보2(w\_21=2.0)
편향: b\_1 = -1 (기본적으로 신중함)
가중합 계산: (2 x 1.5) + (3 x 2.0) + (-1) = 3 + 6 - 1 = 8

활성화 함수 (ReLU 적용): f(8) = 8

결과:  점수 8점 (매우 강력한 신호 발생!)



2\) 은닉 뉴런 h\_2

가중치 지정: (w\_{12}=1.0), (w\_{22}=-2.0)

편향: b\_2 = 0

가중합 계산: (2 x 1.0) + (3 x -2.0) + 0 = 2 - 6 = -4

활성화 함수 (ReLU 적용): f(-4) = 0 (음수는 0으로 차단)

결과: 점수 0점



Step 2. 은닉층

출력층 연산 (최종 전략 결정)은닉층에서 계산된 결과 \[h\_1, h\_2] = \[8, 0]
출력을 결정하는 출력층 뉴런(y\_1, y\_2)으로 넘어갑니다.

1\) 출력 뉴런 y\_1

은닉층과의 가중치: h\_1 연결(1.0), h\_2 연결(0.5),
편향: b\_{y1} = 0
가중합 계산: (8 x 1.0) + (0 x 0.5) + 0 = f{8}



2\) 출력 뉴런 y\_2

은닉층과의 가중치: h\_1 연결(0.2), h\_2 연결(2.0),

편향: b\_{y2} = 0

가중합 계산: (8 x 0.2) + (0 x 2.0) + 0 = f{1.6}



Step 3. 소프트맥스(Softmax)를 통한 최종 확률 변환출력층의 가중합 결과인 \[8, 1.6]이라는 어중간한 숫자를 ‘확률(%)’로 바꿔주는 Softmax 활성화 함수를 거칩니다.

순전파의 최종 결론

순전파 과정을 통해 "99.8%의 확률로 '특정 행동을 출력해라' 라는 최종 예측 결과값을 도출해 내고, 곧바로 출력됌

순전파의 핵심 특징 요약

단방향 흐름: 데이터가 입력(오감) -> 은닉(뇌의 정보 처리) -> 출력(근육 명령) 방향으로만 흘러갑니다.

연산의 목적: 학습을 통해 얻은 현재의 가중치(W)를 바꾸지 않고, 주어진 입력에 대해 가장 최선의 예측/결과값(Y)을 내놓는 것

학습과의 차이: 순전파 단계에서는 아직 학습의 실패 여부를 평가하거나 배우지 않는다. 오직 지금 아는 정보대로 출력는 행위 그 자체


3\. 손실함수 (Loss Function)

"내가 내보낸 출력이 '원하는 결과값'과 얼마나 떨어져 있는가?"



하지만 아직 숙련되지 않은 결과는 예측이다.
목표(정답 Y): 원하는 결과를 내는 최적의 출력을 냄.

실제 내지른 출력(예측 Y): 실제 출력.
오차(Loss): 조금 틀렸다 라고 유연하게 느끼는 것을 넘어, "목표 결과보다 얼마나 빗나갔고, 얼마나 틀렸다"처럼 실패의 크기를 정확한 숫자로 계산해 주는 것이 손실함수이다.

손실함수 값(Loss)이 0이라는 것은, 완벽한 출력을 내는 것이다


손실함수

1\. 평균제곱오차, MSE

연속적인 값을 예측할 때 사용합니다.

L\_{{MSE}} = {1} / {2n}\[sum\_{i=1}^{n}(hat{y}\_i-y\_i)^2]

(y\_i): 정답

(hat{y}\_i): 예측값

예측값이 정답과 멀수록 손실이 커집니다.


4. 경사하강법 (Gradient Descent)"

피드백과 학습을 거치며 최적의 '출력'를 완성해 가는 과정"
경사하강법은 손실함수가 알려준 오차(Loss)를 바탕으로, 가중치(W)를 조금씩 수정해 가는 최적화 동작입니다.

1) 오차 확인 (피드백 / 역전파, Backpropagation)
출력했지만 만족스러운 결과를 내지 못함, 어느 부분에서 틀린 건지 원인을 역추적(역전파)한다.

2) 기울기(Gradient) 계산 — 개선 방향 잡기 현재 자세에서 오차를 줄이려면 어느 방향으로 검술을 수정해야 하는지 계산한다.
기울기가 양수/음수라는 것: 어떤 가중치를 아주 조금 증가시켰을 때 손실이 증가하는지 감소하는지 나타내는 값, 학습량을 늘려야 한다"처럼 오차가 가장 빠르게 줄어드는 방향을 알아내는 것


\- Gradient가 양수이면 해당 가중치를 줄이는 방향이 손실을 줄인다.

\- Gradient가 음수이면 해당 가중치를 늘리는 방향이 손실을 줄인다.

그래서 경사하강법은 Gradient의 반대 방향으로 이동
3) 가중치 업데이트 — 학습률(Learning Rate)
조절방향을 알았으니 다음 시도 때 학습을 수정합니다. 이때 학습률(Learning Rate)이 결정적인 역할을 한다.

학습률이 너무 큰 경우: 컴퓨터가 조급한 마음에 동작을 너무 과하게 수정하여, 오히려 완전히 엉뚱한 방향으로 출력이 된다.

학습률이 너무 작은 경우: 출력을 너무 오래 신경쓰며 고치다보니 완성도를 높이지 못한다.

적절한 학습률: 입력을 어떻게 고쳐야지 오차를 빠르게 줄일 수 있는 최적의 폭으로 자세를 교정합니다.

4) 반복 (Epochs)
학습을 수천번 반복하는 과정입니다. 반복할수록 오차는 점차 줄어들고, 마침내 오차가 최소가 되는 '최적의 자세(Optimal Weights)'에 도달하여 완벽한 출력을 완성하게 됩니다.



\- 역전파(Backpropagation): 손실이 각 가중치에 얼마나 영향을 받는지 Gradient를 계산

\- 경사하강법(Gradient Descent): 계산된 Gradient를 이용해 가중치를 수정

전체 흐름은 다음과 같습니다

{순전파} -> {손실 계산} -> {역전파} -> {가중치 업데이트}
